# SpendWise Dashboard Shell

## Project Description

SpendWise is a modern personal finance dashboard designed to help users view and understand their income, expenses, savings, and spending categories.

This Week 4 project focuses on building the visual dashboard structure using CSS Grid and Flexbox. It uses realistic static financial information and does not include JavaScript functionality.

## Files

### index.html
Contains the structure of the SpendWise dashboard, including the sidebar, navigation menu, header, financial summary, and six expense category cards.

### style.css
Contains all styling for the dashboard. It uses CSS Grid for the main page and category-card layout, Flexbox for the sidebar, header, summary section, and individual cards.

### README.md
Explains the project, its structure, and the technologies used.

## Features

- Responsive dashboard layout
- Sidebar navigation
- Dashboard header
- Financial summary cards
- Six expense categories:
  - Food
  - Transport
  - Rent
  - Entertainment
  - Savings
  - Utilities
- CSS Grid layout
- Flexbox layouts
- CSS custom properties
- Hover micro-interactions
- Keyboard focus effects
- Responsive layout below 768px
- Dark theme using `prefers-color-scheme`

## Responsive Design

The dashboard changes to a single-column layout on screens smaller than 768px.

The responsive layout can be tested using the browser's DevTools Device Toolbar.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Custom Properties
- CSS Media Queries
